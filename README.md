# 🔥 Estação dos Aquecedores

Aplicativo web em Streamlit para suporte técnico, cálculos e orientações sobre aquecedores.

## 🚀 Como Executar

### Pré-requisitos
- Python 3.10 a 3.12

### Instalação
```bash
# Clone o repositório
git clone https://github.com/EstacaodosAquecedores/estacao-aquecedor.git
cd estacao-aquecedor

# Instale as dependências
pip install -r requirements.txt
streamlit>=1.36.0
python>=3.10,<3.13
pandas>=2.2.0
